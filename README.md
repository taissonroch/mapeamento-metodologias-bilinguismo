# Mapeamento das Metodologias de Pesquisa em Psicolinguística do Bilinguismo

Este repositório reúne o dashboard interativo desenvolvido como material complementar ao pôster “Mapeamento das Metodologias de Pesquisa em Psicolinguística do Bilinguismo”, apresentado no XVI Encontro do CELSUL.

O dashboard apresenta gráficos e tabelas relacionados a uma revisão sistemática da literatura sobre metodologias utilizadas em pesquisas de processamento da linguagem na psicolinguística do bilinguismo.
